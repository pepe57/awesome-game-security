# frida-scripts (0xdea)

Collection of **Frida instrumentation scripts** for **dynamic analysis** across **mobile and desktop** platforms. Includes **tracing and enumeration helpers** for **iOS, Android, and Linux**, plus reusable JavaScript snippets for common runtime hook scenarios — method tracing, class discovery, and bypass-oriented experimentation. Primarily used by reverse engineers and application security testers during live runtime analysis. (source: wiki/sources/descriptions/0xdea__frida-scripts.md)

Distinct from [[frida-scripts]] (smartdone/Frida-Scripts; editor tooling / hooking snippets).
