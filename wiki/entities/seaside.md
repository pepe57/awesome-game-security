# Seaside

Internal CS:GO visual cheat framework (0TheSpy; C++). Resolves Source engine interfaces, applies hooking and netvar handling, and uses pattern scanning for game-specific addresses. Presents an ImGui-based DirectX 9 menu for in-process overlay configuration. Core modules cover aim assistance, recoil handling, skin and inventory customization, event listeners, and configuration management. README-tagged `[Internal]`; aimed at researchers studying internal cheat architecture on Source-based titles. (source: wiki/sources/descriptions/0TheSpy__Seaside.md)

Treat as a reference internal framework—not a maintained offset feed or production cheat.
