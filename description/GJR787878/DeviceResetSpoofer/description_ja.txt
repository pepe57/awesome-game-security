DeviceResetSpoofer は、選択したアプリのデータが消去された後、新しいデバイス ID を自動的に割り当てる Android 用 LSPosed モジュールです。Java で書かれ、Xposed フックにより Android ID、広告 ID、IMEI/MEID、Wi-Fi MAC、GSF ID、ビルドフィンガープリント、キャリアメタデータなどの識別子を偽装でき、各フックタイプは個別に切り替え可能です。アプリのプライベートディレクトリ内の隠しセンチネルファイルがシステムブロードキャストに依存せずデータ消去を検出し、モジュールの設定 UI から手動で ID リセットも実行できます。Android 7 から 16 で LSPosed を動かす root 済み端末を対象とし、モバイル端末フィンガープリント、反チート検査、アプリレベルのハードウェア BAN の研究や回避を目的とした研究者・ユーザー向けです。
