DeviceResetSpoofer est un module Android LSPosed qui attribue automatiquement une nouvelle identité d'appareil aux applications sélectionnées après l'effacement de leurs données. Écrit en Java avec des hooks Xposed, il falsifie des identifiants tels que l'Android ID, l'ID publicitaire, l'IMEI/MEID, l'adresse MAC Wi-Fi, le GSF ID, l'empreinte de build et les métadonnées de l'opérateur, chaque type de hook pouvant être activé indépendamment. Un fichier sentinelle caché dans le répertoire privé de l'application détecte les effacements de données sans s'appuyer sur les diffusions système, et les utilisateurs peuvent aussi déclencher manuellement une réinitialisation d'identité depuis l'interface de configuration du module. Il cible les appareils rootés exécutant LSPosed sous Android 7 à 16 et s'adresse aux chercheurs et utilisateurs qui étudient ou contournent l'empreinte mobile, les contrôles anti-triche et les bannissements matériels au niveau des applications.
