DeviceResetSpoofer es un módulo Android LSPosed que asigna automáticamente una nueva identidad de dispositivo a las aplicaciones seleccionadas tras borrar sus datos. Escrito en Java con hooks Xposed, falsifica identificadores como Android ID, ID publicitario, IMEI/MEID, MAC Wi-Fi, GSF ID, huella de compilación y metadatos del operador, con cada tipo de hook activable de forma independiente. Un archivo centinela oculto en el directorio privado de la aplicación detecta borrados de datos sin depender de transmisiones del sistema, y los usuarios también pueden activar reinicios de identidad manualmente desde la interfaz de configuración del módulo. Está orientado a dispositivos con root que ejecutan LSPosed en Android 7 a 16 y está dirigido a investigadores y usuarios que estudian o evaden el fingerprinting móvil, las comprobaciones antitrampas y las prohibiciones de hardware a nivel de aplicación.
