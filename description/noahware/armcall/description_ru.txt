Armcall — это header-only библиотека C++20 для прямых системных вызовов ядра Windows на ARM64. Она разбирает экспорты ntdll, извлекает непосредственный операнд из каждой инструкции SVC и динамически генерирует исполняемые заглушки, которые вызывают svc и возвращаются, не направляя вызовы через import thunk, которые могут перехватывать античит или EDR. Макросы AC_SYSCALL предоставляют простой интерфейс для вызова NT-функций, таких как выделение памяти и запрос системного времени, с подключаемыми абстракциями стандартной библиотеки для пользовательских сред. Полезна для исследований безопасности игр, изучения обхода античита и низкоуровневой обратной разработки Windows на платформах ARM64.
