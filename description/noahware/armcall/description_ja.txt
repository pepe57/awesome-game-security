Armcall は、ARM64 上で Windows カーネル syscall を直接行うためのヘッダオンリー C++20 ライブラリです。ntdll のエクスポートを解析し、各 SVC 命令から即値オペランドを抽出し、svc を呼び出して戻る実行可能スタブを動的に生成します。アンチチートや EDR ソフトウェアがフックする可能性のある import thunk を経由せずに呼び出せます。AC_SYSCALL マクロは、メモリ割り当てやシステム時刻の取得など NT 関数を呼び出すためのシンプルなインターフェースを提供し、カスタム環境向けに差し替え可能な標準ライブラリ抽象化も備えています。ゲームセキュリティ研究、アンチチート回避の調査、ARM64 プラットフォームにおける Windows の低レベルリバースエンジニアリングに有用です。
