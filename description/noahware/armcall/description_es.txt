Armcall es una biblioteca C++20 solo de encabezados para realizar syscalls directos del kernel de Windows en ARM64. Analiza las exportaciones de ntdll, extrae el operando inmediato de cada instrucción SVC y genera dinámicamente stubs ejecutables que invocan svc y retornan sin enrutar las llamadas a través de import thunks que el software anti-cheat o EDR puede interceptar. Las macros AC_SYSCALL proporcionan una interfaz sencilla para invocar funciones NT como asignación de memoria y consultas de hora del sistema, con abstracciones de biblioteca estándar intercambiables para entornos personalizados. Es útil para investigación en seguridad de juegos, estudios de evasión de anti-cheat e ingeniería inversa de Windows de bajo nivel en plataformas ARM64.
