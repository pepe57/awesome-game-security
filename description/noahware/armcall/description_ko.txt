Armcall은 ARM64에서 Windows 커널 syscall을 직접 수행하기 위한 헤더 전용 C++20 라이브러리입니다. ntdll 내보내기를 파싱하고, 각 SVC 명령에서 즉시 피연산자를 추출하며, svc를 호출하고 반환하는 실행 가능한 스텁을 동적으로 생성합니다. 안티치트나 EDR 소프트웨어가 후킹할 수 있는 import thunk를 거치지 않고 호출할 수 있습니다. AC_SYSCALL 매크로는 메모리 할당 및 시스템 시간 조회와 같은 NT 함수를 호출하기 위한 간단한 인터페이스를 제공하며, 사용자 정의 환경을 위한 플러그형 표준 라이브러리 추상화도 지원합니다. 게임 보안 연구, 안티치트 우회 연구, ARM64 플랫폼에서의 Windows 저수준 리버스 엔지니어링에 유용합니다.
