Armcall è una libreria C++20 header-only per effettuare syscall dirette del kernel Windows su ARM64. Analizza le export di ntdll, estrae l'operando immediato da ciascuna istruzione SVC e genera dinamicamente stub eseguibili che invocano svc e ritornano senza instradare le chiamate attraverso import thunk che software anti-cheat o EDR possono intercettare. Le macro AC_SYSCALL forniscono un'interfaccia semplice per invocare funzioni NT come allocazione di memoria e query dell'ora di sistema, con astrazioni della libreria standard sostituibili per ambienti personalizzati. È utile per la ricerca sulla sicurezza dei giochi, studi sull'evasione degli anti-cheat e reverse engineering Windows di basso livello su piattaforme ARM64.
