Armcall est une bibliothèque C++20 header-only pour effectuer des appels système Windows au niveau du noyau directement sur ARM64. Elle analyse les exports de ntdll, extrait l'opérande immédiat de chaque instruction SVC et génère dynamiquement des stubs exécutables qui invoquent svc et retournent sans passer par les import thunks que les logiciels anti-triche ou EDR peuvent hooker. Les macros AC_SYSCALL offrent une interface simple pour invoquer des fonctions NT telles que l'allocation mémoire et les requêtes d'heure système, avec des abstractions de bibliothèque standard interchangeables pour des environnements personnalisés. Elle est utile pour la recherche en sécurité des jeux, les études d'évasion anti-triche et le reverse engineering Windows de bas niveau sur les plateformes ARM64.
