PetalAntiFreecam 是一款 Minecraft 服务器插件，通过从发送给高于该阈值的玩家的区块数据包中移除可配置 Y 高度以下地形，来缓解 freecam 作弊。该插件使用 Java 编写，面向 Paper 与 CanvasMC 1.21，借助 PacketEvents 拦截出站区块数据，并用 ChunkMasker 将隐藏区块段替换为空气，同时过滤方块实体；玩家移动时按每 tick 预算刷新区块，以限制网络负载。管理员可调恢复与隐藏 Y 阈值、运行时重载配置，并可选用 CanvasMC 可见性监听器处理异步传送。它面向需要轻量、服务端反作弊以对抗客户端相机漏洞的多人服务器运营者，而非内核级或商业反作弊套件。
