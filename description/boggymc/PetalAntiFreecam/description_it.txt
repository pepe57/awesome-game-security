PetalAntiFreecam è un plugin per server Minecraft che mitiga il cheating freecam rimuovendo dal terreno sotto un livello Y configurabile i pacchetti di chunk inviati ai giocatori che si trovano sopra quella soglia. Scritto in Java per Paper e CanvasMC 1.21, intercetta i dati dei chunk in uscita con PacketEvents e usa un ChunkMasker per sostituire le sezioni nascoste con aria filtrando le tile entity, quindi aggiorna i chunk quando i giocatori si spostano con un budget per tick per limitare il carico di rete. Gli amministratori possono regolare le soglie Y di ripristino e occultamento, ricaricare le impostazioni a runtime e usare opzionalmente i listener di visibilità CanvasMC per la teletrasportazione asincrona. È pensato per gli operatori di server multigiocatore che necessitano di un anti-cheat leggero lato server contro exploit della camera lato client, piuttosto che suite anti-cheat a livello kernel o commerciali.
