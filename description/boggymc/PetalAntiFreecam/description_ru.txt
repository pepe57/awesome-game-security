PetalAntiFreecam — плагин для сервера Minecraft, который смягчает чит freecam, удаляя из пакетов чанков, отправляемых игрокам выше заданного порога, ландшафт ниже настраиваемого уровня Y. Написан на Java для Paper и CanvasMC 1.21; перехватывает исходящие данные чанков через PacketEvents и с помощью ChunkMasker заменяет скрытые секции воздухом, фильтруя tile entity, затем обновляет чанки при перемещении игроков с бюджетом на тик, чтобы ограничить сетевую нагрузку. Администраторы могут настраивать пороги Y для восстановления и скрытия, перезагружать настройки во время работы и при необходимости использовать слушатели видимости CanvasMC для асинхронной телепортации. Ориентирован на операторов многопользовательских серверов, которым нужен лёгкий серверный античит против клиентских эксплойтов камеры, а не античит на уровне ядра или коммерческие решения.
