MOABile — это универсальный набор инструментов мобильной безопасности, объединяющий профессиональные утилиты для тестирования в едином текстовом интерфейсе для оценки безопасности приложений Android и iOS с настольного компьютера. Написанный на Python, он поддерживает одновременное управление несколькими устройствами, двухпанельную передачу файлов между хостом и мобильными устройствами, зеркалирование экрана в реальном времени через scrcpy и автоматическую настройку Frida и Objection для инспекции и исследования приложений во время выполнения. Набор интегрирует ADB для Android, а также iproxy и ioscpy для подключения iOS, предоставляя эти возможности через терминальный интерфейс с навигацией стрелками и обновлением статуса в реальном времени. Он предназначен для специалистов по тестированию на проникновение, исследователей мобильной безопасности и разработчиков, которым нужен доступный способ проводить локальную оценку безопасности на собственных устройствах.
