MOABile は、プロフェッショナル向けテストユーティリティを単一のテキストベースインターフェースに統合した、オールインワンのモバイルセキュリティツールキットです。デスクトップコンピュータから Android および iOS アプリケーションのセキュリティを評価できます。Python で書かれており、複数デバイスの同時管理、ホストとモバイルデバイス間のデュアルペインファイル転送、scrcpy によるライブ画面ミラーリング、ランタイムアプリの検査と探索のための Frida および Objection の自動セットアップをサポートしています。Android 向けに ADB を、iOS 接続には iproxy と ioscpy を統合し、これらの機能を方向キーで操作可能なターミナル UI からリアルタイムのステータス更新とともに提供します。ペネトレーションテスター、モバイルセキュリティ研究者、および所有するデバイスでローカルセキュリティ評価を行う必要がある開発者を対象としています。
