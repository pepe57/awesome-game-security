MOABile 是一款一體化行動安全工具包，將專業測試工具整合到單一文字介面中，便於從桌面電腦評估 Android 和 iOS 應用程式的安全性。該工具使用 Python 編寫，支援多裝置同時管理、主機與行動裝置之間的雙窗格檔案傳輸、透過 scrcpy 進行即時螢幕鏡像，以及自動設定 Frida 和 Objection 以進行執行階段應用程式檢查與探索。工具包整合 ADB 用於 Android，並透過 iproxy 和 ioscpy 實現 iOS 連線，這些功能均透過可用方向鍵導覽的終端機 UI 提供，並附帶即時狀態更新。它面向滲透測試人員、行動安全研究人員以及需要對自有裝置進行本地安全評估的開發者。
